## 📌 Overview

**AI Robot Web** is the web documentation and control portal for the **SARAS AI Robot**. It presents the hardware schematics, software architecture, features breakdown, live system logs, and V2 portal updates.

---

## ✨ Features & Pages

- 🏠 **`index.html`**: Project overview, mission, and live status.
- 🏗️ **`architecture.html`**: System diagram, software stack, and module interactions.
- 🔧 **`hardware.html`**: GPIO pinouts, motor driver wiring, and sensor schematics.
- 💻 **`code.html`**: Core modules breakdown (Voice, AI, Motor control, Web server).
- 📜 **`logging.html`**: Telemetry and conversation log viewer.
- 🚀 **`V2/`**: Updated Version 2 portal design and component improvements.
